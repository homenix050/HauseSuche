# Пошук житла в Берліні

Статичний сайт українською мовою. Початкова структура під GitHub Pages або інший статичний хостинг.

## Вміст
- `index.html` — головна сторінка;
- `seminars/seminar-1/index.html` — сторінка першого семінару;
- `seminars/seminar-1/notes/index.html` — конспект, перетворений Pandoc 3.13 і доповнений навігацією сайту;
- `transcript/`, `audio/`, `presentation/`, `highlights/` — сторінки для решти матеріалів;
- `css/style.css` — спільні стилі.

## Додавання матеріалів
- Транскрипцію додайте в `seminars/seminar-1/transcript/`;
- аудіо — в `audio/` (за замовчуванням сторінка очікує `audio-file.m4a`);
- PDF презентації — в `presentation/` під назвою `presentation.pdf`;
- важливі теми — в `highlights/`.

Усі посилання відносні. Перед публікацією перевірте дозволи на публічне розміщення аудіо, презентації та транскрипції.
